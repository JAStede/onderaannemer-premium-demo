# Premium onderaannemer-demo — LJ Studio

Een fictieve, responsieve homepage voor acquisitie van bouw- en infrabedrijven.

## Inhoud
- `index.html`: alle homepage-secties, navigatie, fictief logo, footer
- `style.css`: responsive ontwerp, hover- en scrollanimaties
- `script.js`: mobiele navigatie, slideshow, tellers en scrollanimaties

## Belangrijk vóór klantgebruik
- **VAN DIJK BOUW & INFRA is fictief.** Alle cijfers (250 projecten, 18 jaar, 35 vakmensen, 98% tevredenheid), contactgegevens, KvK, btw-id en IBAN zijn uitsluitend voorbeelden en mogen niet als echte bedrijfsclaims worden gepresenteerd.
- Vervang sfeerbeelden door eigen foto's of correct gelicentieerde afbeeldingen; huidige foto's worden vanaf Unsplash geladen.
- De contactknop in de demo mailt LJ Studio; fictieve contactgegevens zijn niet aanklikbaar.
- De website is `noindex,nofollow` zodat een democoncept niet bedoeld is voor zoekindexering.
- Privacyverklaring en voorwaarden zijn placeholders en moeten voor een echte website worden opgesteld.
- Er is geen backend of contactformulier aangesloten.

## Publiceren op GitHub Pages
1. Maak een nieuwe openbare repository, bijvoorbeeld `onderaannemer-premium-demo`.
2. Upload `index.html`, `style.css` en `script.js` in de root.
3. Ga naar Settings → Pages → Deploy from a branch → `main` / root → Save.
4. Open de URL die GitHub Pages toont. Voor een repo onder JAStede is die doorgaans `https://jastede.github.io/onderaannemer-premium-demo/`.

Dit ontwerp is een demonstratie en geen officiële website van een bestaande aannemer.
